# Odin Calculator

An HTML, CSS, and JavaScript project that develops a basic functional calculator capable of computing two-operand operations with +, -, /, and * with those operands being either integers or floating point values.

## Description

[Odin Calculator](https://www.theodinproject.com/lessons/foundations-calculator) is the *final* project in the foundation portion of the [Odin Project](https://www.theodinproject.com/paths)
designed to give learners an opportunity to tie together everything they have learned so far in HTML, CSS, and JavaScript to build and design a basic calculator. In the HTML file, you will find the skeletal layout of the calculator. The CSS mostly contains flexbox-related styling along with other small changes to make the calculator more appealing. Lastly, you will see the JavaScript implement and handle event listeners based on which button is pressed. Ultimately, the JavaScript file handles all the bookkeeping involved in how continuous interaction after evaluation behaves, the usage of the negative symbol, and the usage of the decimal, all to serve the purpose of saving users from themselves and properly computing the user's input.
